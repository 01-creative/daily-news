安全研究员 Yuhang Wu（depthfirst）于 7 月 24 日公开了 GitLab CE/EE 的完整 RCE 漏洞链及 PoC 利用代码，攻击者仅需拥有任意仓库的 Push 权限，即可通过提交精心构造的 Jupyter Notebook（.ipynb）文件触发 Oj JSON 解析库的内存损坏漏洞（越界写入 + 堆指针泄露），最终以 `git` 用户身份执行任意系统命令。该漏洞链无需管理员权限、无需 CI/CD 访问、无需受害者交互。受影响版本为 GitLab 15.2.0–18.10.7 / 18.11.0–18.11.4 / 19.0.0–19.0.1，修复版本为 18.10.8 / 18.11.5 / 19.0.2。GitLab 于 6 月 10 日以"Bug 修复"而非安全公告形式发布补丁，未分配 CVE 编号，导致大量用户未能及时感知风险——直至 PoC 公开后才引发广泛关注，腾讯云、长亭等国内安全厂商于 7 月 26 日密集发布风险通告。国内高校广泛使用 GitLab 自建代码托管与课程协作平台，建议立即核查版本并升级。

MemGhost：一封邮件即可向 AI Agent 植入持久性虚假记忆
南洋理工大学等机构的研究人员提出 MemGhost 自动化攻击框架，仅需发送一封精心构造的邮件，即可诱使 AI Agent 将虚假信息写入其持久记忆文件（如 MEMORY.md），且 Agent 的可见回复不留下任何痕迹。攻击在 GPT-5.4 驱动的 OpenClaw Agent 上端到端成功率达 87.5%，在 Claude Code SDK（Sonnet 4.6）上达 71.4%，三种专用防御机制均被绕过（误报率 >90%）。CSA 于 7 月 26 日发布深度分析报告，指出该攻击揭示了 AI Agent 长期记忆机制的结构性安全缺陷。论文此前已于 arXiv 公开（2607.05189）。

📰 首个自主 Agent 勒索软件 JADEPUFFER 新增 AI 模型定向加密变种 ENCFORGE
