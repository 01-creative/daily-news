【高危·EDUSRC】CVE-2026-10050 — Eclipse Jetty Digest 认证编码缺陷致认证绕过（CVSS 8.7）

Eclipse Jetty 于 8 月 4 日公开 CVE-2026-10050，影响 Jetty 9.4.0–9.4.58、10.0.0–10.0.26、11.0.0–11.0.26、12.0.0–12.1.9 及对应 EE8/EE9 版本。根因在于 `DigestAuthentication.apply()` 方法使用 ISO-8859-1 编码处理密码，导致中、日、韩、阿拉伯、西里尔等非拉丁字符被统一替换为 `?`（0x3F），攻击者仅需知道目标用户名即可构造全 `?` 字符的碰撞密码，产生与原始密码相同的 MD5 Digest 哈希值，无需认证即可以该用户身份登录。此外，合法非拉丁字符密码用户可能因编码不一致而无法正常认证。Jetty 是 Java Web 应用最广泛的内嵌服务器之一，大量高校业务系统（教务、科研管理、统一认证等）基于 Jetty 或 Spring Boot（内嵌 Jetty）构建，建议立即升级至 9.4.63 / 10.0.31 / 11.0.31 / 12.0.36 / 12.1.10 或更高版本。
→ https://nvd.nist.gov/vuln/detail/CVE-2026-10050
→ https://github.com/advisories/GHSA-2fvj-hgj9-j2gr

【中危·CNVD】CVE-2026-18723 — DWSurvey 问卷系统未授权状态篡改漏洞，PoC 已公开

国产开源问卷系统 DWSurvey（调问）6.0 至 6.14.0 版本的问卷状态处理器 `/api/dwsurvey/app/survey/up-survey-status.do` 存在授权绕过漏洞，低权限攻击者可通过网络直接修改任意问卷状态（发布/停用/删除）。公开 PoC 已可获取，厂商未回应漏洞报告，暂无官方补丁。DWSurvey 在高校问卷调查、课题申报等场景中有部署，建议在补丁发布前对相关端点实施网络层访问控制。
