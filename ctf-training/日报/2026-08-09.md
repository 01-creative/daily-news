📰 ChainDrop：自传播 npm 供应链蠕虫感染 400+ 软件包，区块链 C2 抗关停

Elastic Security Labs 于 8 月 6 日发布对"Shai-Hulud"恶意软件家族最新变种 ChainDrop 的详细技术分析。8 月 3–4 日，攻击者入侵广泛使用的 npm 库 keyv（月下载量超 6 亿）维护者 GitHub 账号，通过 monorepo 的 `preinstall` 钩子在 400+ 个 npm 包中植入恶意载荷，合计月下载量超 20 亿次。受影响包包括 `keyv`、`flat-cache`、`cacheable-request`、`cacheable` 等，波及 Deliveroo、ServiceTitan、Qlik 等企业。

技术亮点：① 不依赖硬编码 C2 域名，而是查询以太坊智能合约 `0xE1f2...` 动态获取外传端点——攻击者仅需更新合约即可轮换基础设施，传统域名下架手段无效；② 载荷扫描 300+ 种凭据模式，窃取 AI 工具密钥、云平台凭据、CI/CD 密钥后通过 AES-256-GCM 加密外传；③ 蠕虫自我传播——利用窃得的 npm token 向受害者所有可写包注入恶意代码并自动发布新版本；④ 在 `.claude/settings.json` 和 `.vscode/tasks.json` 中植入钩子，仅打开被篡改仓库即可触发感染。建议将 npm 升级至 v12+（默认拦截 `preinstall` 钩子）、轮换所有 CI/CD 及 npm 凭据。
