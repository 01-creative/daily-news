【高危·CNVD】CVE-2026-18574 — Check Point Security Management Server 未认证远程命令执行漏洞（CVSS 9.3）

Check Point 于 8 月 3 日发布安全公告 sk185222，修复 Security Management Server 及 Multi-Domain Security Management Server（MDS）中一个认证绕过漏洞（CWE-288）。未经认证的远程攻击者可通过网络访问管理服务接口，绕过认证机制执行任意系统命令，进而篡改防火墙策略、修改管理员权限或关闭审计日志，导致安全边界完全失效。受影响版本覆盖 R80 至 R82.10 全部版本线，修复通过各分支 Jumbo Hotfix Accumulator 发布；Smart-1 Cloud 客户已自动防护。尚无在野利用证据，但攻击复杂度低，建议高校中自建 Check Point 管理平台的网络中心尽快应用热修复，并临时收紧 Trusted Clients 白名单。

📄 Hollow-LLM Attack：当 ZK 证明"诚实推理"却无法证明"用大模型推理"

IEEE S&P 2026 接收论文（arXiv 2607.28884，8 月 3 日发布），由 USC、MIT 及 Ohio State 联合团队发表。研究揭示了一个此前被忽视的"努力差距"（Effort Gap）：当前零知识证明（ZK）LLM 推理验证协议仅能证明输出相对于权重的等式正确性，却无法约束生成输出所需的实际计算量。攻击者可在模型中嵌入"幽灵权重"（Ghost Weights）——其代数结构使有效计算坍缩，但仍通过 ZK 验证电路并产生有效证明——从而用小模型的计算成本冒充大模型推理，骗取服务费用且无质量损失。论文形式化了这一安全盲区，给出了可组合进标准 Transformer 块的幽灵权重族构造方法。该研究对 AI 推理外包与模型即服务（MaaS）生态的信任模型提出了根本性质疑。
