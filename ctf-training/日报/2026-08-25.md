【高危·EDUSRC】CVE-2026-66897 — Canonical LXD 实例模板路径穿越致宿主机 root 代码执行（CVSS 9.9）

LXD 容器引擎在解析实例模板 `metadata.yaml` 时存在校验与使用不一致：目标路径先经受限的 `os.Root` 句柄校验，随后却用未受限的字符串路径 `os.Create` 创建文件，攻击者可借 `PUT /1.0/instances/{name}/metadata`（需容器编辑权限）或导入携带恶意模板的镜像越出容器根文件系统，覆盖宿主机任意 root 属主文件并最终实现宿主机 root 代码执行；模板在每次容器启动时重新应用，具备持久性。影响 4.0 < 4.0.13、5.0 < 5.0.9、5.21 < 5.21.7、6.0 < 6.10，修复版本已发布（4.0.13/5.0.9/5.21.7/6.10）。LXD 在高校教学科研容器云、开发实训环境中部署普遍，建议升级并限制不可信镜像的导入。

【高危】CVE-2026-71921 — DrayTek VigorSwitch 系列 setget.cgi 命令注入（CVSS 9.8）

DrayTek 于 8 月 24 日发布 DSA-2026-003，修复 VigorSwitch 全系列多型号 Web 管理接口 `setget.cgi` 中 `pass` 字段未过滤即进入系统命令执行的问题：远程攻击者可注入命令并以 root 权限执行，进而完全控制交换机及所辖网段。第三方分析（IONIX、VulnCheck）评定为预认证可利用；DrayTek 官方口径略保守，称实际利用可能需要管理凭据——无论哪种情况都建议尽快按型号升级到修复固件（3.9.10 / 2.10.6 / 2.10.7 / 3.10.6 / 2.9.10），并收敛 Web 管理面到可信管理网段。同一公告还覆盖 `mainfunction.cgi` 空指针/目录穿越/缓冲区溢出及 `pingtrace` 命令注入（CVE-2026-71924，需管理员，8.6）。VigorSwitch 常见于高校分院系、宿舍及中小规模汇聚节点，请盘点在网设备。
