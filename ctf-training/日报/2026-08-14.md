【高危·EDUSRC】GeoServer `jsonArrayContains` SQL 注入零日（未修复，CVSS 9.8，在野利用尝试中）

开源地理信息服务器 GeoServer 曝出未修复零日：CQL 过滤处理中的 `jsonArrayContains` 函数未对用户输入做参数化处理，未经认证的攻击者构造恶意 CQL 语句即可注入任意 SQL，导致数据泄露与篡改；当后端数据库账号权限较高时（PostGIS 超级用户、H2 特定配置、MSSQL 管理员），可进一步实现远程代码执行。漏洞由研究员 @q1uf3ng 于 8 月 12 日公开披露，至今无 CVE 编号、无官方补丁；watchTowr 监测到披露后数小时内即出现数百次探测，截至 8 月 13–14 日以侦察试探为主，尚未见确认失陷。GeoServer 在高校地理信息、遥感、科研数据平台中部署广泛，建议立即收敛互联网暴露面、以 WAF/反代拦截含 `cql_filter=...jsonArrayContains...` 的请求，并对数据库账号做最小权限收敛。

【高危】ShieldBreak — Windows Defender 提权零日（CVE-2026-50656 补丁绕过，公开 PoC，未修复）

研究员 "Chaotic Eclipse"（MSNightmare）公开了针对微软七月补丁的完整绕过 PoC：ShieldBreak 利用用户态回调钩子，在 Defender 云端水合扫描（Cloud Filter API / cfapi）期间篡改文件内容，实现本地提权至 SYSTEM——此前修复 RoguePlanet（CVE-2026-50656）的补丁被证明不完整。PoC 已在 Windows 11 25H2 与 Windows Server 2025 上以 100% 成功率验证（Windows 10 亦疑受影响），Kevin Beaumont 与 Will Dormann 均独立确认。微软尚未发布修复，仅表示"正在调查"。该利用需 Defender 启用且为本地提权，不属远程攻击，但影响面覆盖几乎所有 Windows 端点：建议开启 Defender 防篡改、将 ASR 规则设为阻止模式，并监控 MsMPEng.exe、wermgr.exe 等异常进程行为。
