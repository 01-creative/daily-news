**Cryptographic Context Injection：把恶意指令"加密"后再交给 AI 智能体（针对 GitHub Copilot CLI）**

**10/11** 由 Adversa AI 公开：在**自动模式**下，**单张网页**即可诱导 Copilot CLI 读取本地敏感文件（如 `.env.prod`）并把内容外带，**全程 28 秒、无确认提示**。新颖之处在绕过检测的方式——恶意指令以**密文 + 密钥 + "用 Python 解密"**的形式投递：智能体在自己的代码运行时里解密，**明文只作为"它刚运行的代码的输出"出现**；而内容分类器读文本、不执行密码运算，因此**没有任何可拦的明文字符串**。该手法被命名为 **Cryptographic Context Injection（CCI）**。

披露过程本身也值得记：Adversa 于 **9/17** 报 GitHub 漏洞赏金，**10/1** GitHub 验证了行为但**判定"非漏洞"、不给 CVE**，Adversa 明确表示不认同。对已把编码智能体接入内网、并依赖"文本过滤"做护栏的团队而言，这是一堂**"提示注入可以借密码学绕过文本检测"**的示范课：把"能读什么文件"这条边界，落到**工具白名单、工作目录限制与出网管控**上，而不是只看它说了什么。
