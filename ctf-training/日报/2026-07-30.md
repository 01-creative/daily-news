🔥【高危·EDUSRC】Broadcom 紧急修复 VMware 三大关键漏洞：vCenter 认证绕过 + 远程代码执行 + ESXi 虚拟机逃逸

Broadcom 于 7 月 29 日发布安全公告 VMSA-2026-0006，修复 VMware 产品线五个漏洞，其中三个为 Critical 级别，均无临时缓解措施：

① CVE-2026-59309（CVSS 9.8）— vCenter Server 认证绕过：VMware Directory Service 存在缺陷，攻击者仅需网络访问 vCenter 即可绕过认证机制获取未授权系统访问权限。影响 vCenter 8.0、Cloud Foundation / vSphere Foundation 9.x 等全系产品。

② CVE-2026-59310（CVSS 9.8）— vCenter Server 目录穿越致远程代码执行：vCenter Syslog 服务器存在目录遍历漏洞，攻击者通过网络访问即可执行任意代码，与 CVE-2026-59309 组合可形成完整的未认证→RCE 攻击链。

③ CVE-2026-47876（CVSS 9.3）— ESXi VMXNET3 虚拟机逃逸：VMXNET3 虚拟网卡存在越界写入，VM 内具有本地管理员权限的攻击者可突破隔离在 ESXi 宿主机上执行代码。使用非 VMXNET3 网卡的 VM 不受影响。

以上漏洞需升级至 vCenter 8.0 U3k / ESXi 9.1.0.0200 / ESXi 9.0.2.0100 / ESXi80U3k 等版本修复。Broadcom 表示目前未发现在野利用证据，但 vCenter 作为高校虚拟化集群核心管理平台，互联网暴露面须在 72 小时内完成评估与升级。

→ https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/38017

🔥【高危】CVE-2026-59726 — Ruflo AI Agent 平台 MCP Bridge 未认证远程代码执行（CVSS 10.0）

Noma Labs 于 7 月 29 日公开披露开源 AI Agent 编排平台 Ruflo（原 Claude Flow，GitHub 66,000+ Stars，约百万活跃用户）中存在代号"RufRoot"的满分漏洞。Ruflo 默认 Docker Compose 部署将 MCP Bridge 端口 3001 绑定至 0.0.0.0，该 Bridge 以零认证方式暴露了 233 个工具端点（含 Shell 命令执行 `ruflo__terminal_execute`），攻击者仅需向 `/mcp` 端点发送单次未认证 HTTP POST 请求即可实现完整远程代码执行。一旦突破，攻击者可窃取容器内所有 LLM API 密钥（OpenAI/Anthropic/Google 等）、读取全部用户对话记录、向 AgentDB 学习存储注入恶意模式以持续影响未来 AI 输出，甚至利用窃取的 API 密钥在受害者计算资源上创建攻击者控制的 Agent 集群。漏洞于 6 月 30 日私下报告，修复版本 3.16.3 已于 24 小时内发布。高校 AI 实验室及自建 AI Agent 平台需立即检查 Ruflo 部署暴露面、轮换所有 LLM API 密钥并升级。

→ https://thehackernews.com/2026/07/ruflo-mcp-flaw-lets-unauthenticated.html
→ https://noma.security/blog/rufroot-the-mcp-bridge-vulnerability-that-turns-agents-into-rogue-admins-cve-2026-59726/

⚠️【高危·CNVD】CVE-2026-58179 — Apache Traffic Server regex_remap 插件栈溢出致远程内存破坏（CVSS 8.1 / CVSS v4 9.2）

Apache Traffic Server 8.0.0–10.1.3 的 `regex_remap` 插件存在栈缓冲区溢出漏洞（CWE-121），未经认证的远程攻击者通过构造超大或恶意的正则替换模式即可触发内存破坏，可能导致任意代码执行或拒绝服务。修复版本 9.2.15 / 10.1.4 已发布。ATS 作为企业级 HTTP 反向代理/缓存，在部分高校 CDN 与 API 网关场景中有所部署，建议排查并升级。
