【高危·EDUSRC】CVE-2026-66066 — Ruby on Rails Active Storage 任意文件读取及远程代码执行（CVSS 9.5）

Rails 框架核心组件 Active Storage 在使用 libvips（Rails 7.0 起默认图片处理器）处理图片变体时，未禁用 libvips 中标记为"unsafe"的操作。未认证攻击者上传特制图片即可触发任意文件读取，泄露 secret_key_base、数据库凭据、云存储密钥等，进而实现远程代码执行（Rapid7 命名为"KindaRails2Shell"）。

影响版本：Rails 7.0–7.2.3.1 / 8.0.0–8.0.5 / 8.1.0–8.1.3（6.x 手动启用 Vips 也可能受影响）。修复版本 7.2.3.2 / 8.0.5.1 / 8.1.3.1 已发布，但需同时确保 libvips ≥ 8.13，否则应用将拒绝启动。漏洞由 Ethiack 和 GMO Flatt Security 独立发现，完整利用链暂未公开（预计 8 月 28 日前披露），GitHub 已有 PoC，暂未观察到在野利用。

国内大量高校门户、选课系统、课程平台基于 Rails 构建——一旦攻击者读取 Rails 密钥即可伪造会话、解密 Cookie、接管管理后台。建议紧急排查并轮换全部密钥（含数据库密码、云存储 Access Key、第三方 API Token）。
