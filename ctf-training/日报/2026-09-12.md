A2ABreak：对 A2A 智能体互操作协议的系统性安全分析（arXiv:2609.10871，9/11）

针对 Linux 基金会主导的 Agent2Agent（A2A）协议——正在成为跨组织多智能体通信的"水平层"——做首次系统性安全分析：以 LLM 辅助从自然语言规范中抽取并验证有限状态机（929 条形式化陈述 → 37 状态 / 76 迁移），在"完全合规假设"下做对抗性推理，发现 **11 个协议级漏洞**，且无需任何实现缺陷即可触达，包括未受保护的上下文标识符导致的跨客户端上下文注入、多跳委托链中的身份丢失致凭据收集、以及恶意智能体以未经证实的"能力声明"外泄数据。零样本 LLM 基线在同一规范上未确认任何发现，说明协议安全分析需要显式形式化基础。正在接入 A2A 的团队值得据此重做信任边界设计。

→ https://arxiv.org/abs/2609.10871

MCPSEC：仅凭描述即可发现 MCP 服务器间接提示注入（arXiv:2609.10854，9/11）

提出"无盒（no-box）漏洞分析"新范式：分析师既无系统访问权、也无运行时交互，只有描述预期输入/输出/副作用的功能元数据，据此推断"所有与该元数据一致的实现都必然存在的缺陷"。原型 MCPSEC 仅用工具注册时可见的元数据，对 20 个广泛使用的 MCP 服务器、177 个工具做间接提示注入检测：人工确认 95 个工具存在漏洞，MCPSEC 命中 143 个、其中 94 个为真实确认漏洞（**98.9% 召回**），优于 LLM 基线（80 个 / 84.2%）。对正在把 MCP 服务器接入校园智能体/自动化流程的团队，这是一套可在部署前先跑一遍的静态闸门。

→ https://arxiv.org/abs/2609.10854

SpecGuard：把推测解码变成"免费"的后门检测信号（arXiv:2609.11799，9/11）

作者含 Mark Russinovich、Ahmed Salem 等（微软背景）：观察到后门被触发时目标模型会偏离干净草稿模型的预期，使推测解码的**草稿令牌接受率**发生系统性偏移——据此把每次 accept/reject 决策聚合为每查询的接受率统计量，从而在正常服务路径上完成后门检测。**无需输入扰动、无需辅助检测模型、无需额外生成或前向计算**，即零额外算力开销；论文形式化了该信号出现的条件，并证明攻击者若要压制它就必须削弱后门本身。对自己部署开源权重模型、担心第三方 checkpoint 后门的高校 AI 团队，这是一条可以"顺手打开"的监测线（对自适应攻击者的有效性仍待实证）。

→ https://arxiv.org/abs/2609.11799

ToxicRAG：单文档"知识更新叙事"即可投毒 RAG 系统（arXiv:2609.11082，9/11）

既有 RAG 知识投毒多依赖多篇注入文档或直接断言目标答案的模板。ToxicRAG 改为**每个目标仅一篇文档**，并把虚假信息包装成可信的"知识更新叙事"：先承认原有结论、再编造推翻它的事件、最后把攻击者选定的答案归于权威来源；可选的自校验回路还会迭代修订候选文档。在 Natural Questions、HotpotQA、MS-MARCO 各 100 个目标问题、4 个受害 LLM × 4 个稠密检索器的 12 组组合上，攻击成功率达 **0.61–0.91**，且每组均不劣于最强基线（领先 0–11 个百分点）。以检索语料为核心的知识库场景（校园问答、制度检索）应据此加强来源溯源与事实一致性校验。

→ https://arxiv.org/abs/2609.11082

📰 佛罗里达州驾照库（DAVID）遭入侵，ShinyHunters 索赎并设 9/11 期限

佛罗里达州公路安全与机动车管理局（FLHSMV）确认其"驾驶人及车辆信息数据库"（DAVID）被入侵：入侵者使用的是**一名 Plant City 警局员工存放在个人电子设备上、未妥善保管的凭据**。勒索团伙 ShinyHunters 认领该攻击，称借"密码重置漏洞"拿下多个账户并枚举记录 ID 下载驾照数据与照片，宣称窃取逾 **20 万条**记录（含驾照、社保号、住址），并公布疑似 DAVID 中 Jeffrey Epstein 的档案作为佐证；该数字未获 FLHSMV 核实，官方亦未披露实际受影响人数。FLHSMV 已联合州数字服务局与州执法部门调查并通报州检察长，攻击者一度设定 9/11 为公开数据的期限。此案与本报 9/3 报道的 IDScan/Nexus 事件无证据关联，但再次指向同一教训：**身份核验与执法查询类系统的高权限凭据一旦落到个人设备，就等于把整库数据置于风险之中**——高校一卡通、门禁、宿管等系统应强制最小权限与专用终端，禁止高权凭据存放于个人设备。

📰 Veradigm 遭第三方供应商 API 凭据失窃，The Gentlemen 索赎 3.5 万患者记录
