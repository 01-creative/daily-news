【高危·EDUSRC】CVE-2026-17556 — GitHub Enterprise Server 未认证路径遍历漏洞（CVSS 8.8）
GitHub 于 8 月 5 日修复了 GHES 中一个严重的未认证路径遍历漏洞（CWE-22），攻击者仅需在 HTTP 请求头 `X-GitHub-Request-Id` 中植入路径穿越载荷，即可诱导服务器递归删除任意文件与目录——包括 Git LFS 对象、Release 资产、附件与头像等全部用户存储数据。该漏洞无需任何认证或用户交互，即使在私有模式下也可利用。受影响版本覆盖 GHES 3.17.0–3.21.3 全部分支，修复版本为 3.17.19 / 3.18.13 / 3.19.10 / 3.20.6 / 3.21.4。国内高校大量使用 GHES 自建代码托管与课程协作平台，建议立即升级；若暂无法升级，应限制 GHES 仅允许可信网络访问，或在反向代理/WAF 层过滤 `X-GitHub-Request-Id` 头。
→ https://www.ionix.io/threat-center/cve-2026-17556/
→ https://nvd.nist.gov/vuln/detail/CVE-2026-17556

【中危·CNVD】CVE-2026-7693 — WordPress Backup Migration 插件命令注入漏洞（CVSS 7.2）
WordPress 备份迁移插件（Backup Migration）2.1.5.1 及之前版本存在认证后 OS 命令注入漏洞（CWE-77），管理员用户通过 `restoreBackup()` AJAX 接口的 `file` 参数可执行任意系统命令。该漏洞是 CVE-2023-7002 的补丁绕过——原修复仅校验了 URL 路径，未覆盖文件路径。Wordfence 于 8 月 4 日公开，修复版本为 2.1.5.2。WordPress 在高校网站中部署广泛，使用该插件的站点应尽快升级。
→ https://www.wordfence.com/threat-intel/vulnerabilities/wordpress-plugins/backup-backup/backup-migration-2151-authenticated-administrator-os-command-injection-via-file-parameter

Exposed by Design：互联网 MCP 服务器大规模动态安全评估
Nicolás Padilla 于 7 月 31 日提交至 arXiv 的论文首次对互联网上公开暴露的 Model Context Protocol（MCP）服务器进行动态行为安全评估。通过 11 个数据源发现超 21,000 个 MCP 实例，确认 640 个生产服务器，并对其中的 414 个进行了主动审计。结果触目惊心：91.8% 的服务器未部署 OAuth 认证，687 个工具实例暴露无访问控制的 Shell 执行能力，发现 68 个可报告漏洞（含 SQL 注入、SSRF 直通云元数据服务、Prompt 注入、路径穿越），且 41.6% 的服务器在 3 天内即消失——侧面反映 MCP 部署的"打了就跑"模式。作者同步开源了测试框架 Corvus。该研究揭示了 MCP 协议设计中安全优先级的缺失，对正在大规模接入 MCP 的 AI Agent 生态有重要警示意义。
→ https://arxiv.org/abs/2608.00150
