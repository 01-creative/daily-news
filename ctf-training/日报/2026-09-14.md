【高危·EDUSRC】CVE-2026-85706 — GitLab 自管实例未认证任意文件读取（CVSS 10.0），已入 KEV 并遭全网扫描

GitLab 9/10 发布 19.3.2 / 19.2.6 / 19.1.8 紧急补丁：commits API 存在路径穿越叠加缺失鉴权（CWE-22），未认证者仅需一个 HTTP POST 携带特制 `file.path`，即可读取 GitLab 服务账号权限下的任意文件——secrets.yml、数据库凭据、CI/CD 变量、SSH 私钥，前置条件仅是实例上存在至少一个公开项目。9/11 CISA 将其纳入 KEV（BOD 26-04，联邦限期 9/14 即今日），watchTowr 于 9/11 06:00 UTC 已观测到在野利用探测，GitHub 同日冒出至少 5 个公开 PoC。影响自管 CE/EE 18.7 起至 19.1.8 / 19.2.6 / 19.3.2 之前（全球约 2 万+ 实例）。高校自建 GitLab 做教学代码托管且普遍存在公开项目，命中条件极易满足；请立即升级，并按"可能已失陷"标准审计 `POST /api/v4/projects/{id}/repository/commits/` 中含 `file.path` 的请求、轮换一切可能外泄的凭据。

【高危】CVE-2026-85102 / CVE-2026-85103 — Check Point Quantum VPN 证书解析预认证 RCE（CVSS 9.8 ×2）
