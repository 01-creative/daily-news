【高危·重大】微软 9 月补丁日创纪录修复约 974 个 CVE，其中两个零日已遭在野利用

9 月 8 日（周二补丁日）微软发布史上最大规模安全更新：SecurityWeek 口径 974 个 CVE（各统计口径 966–999 不等），其中约 112 个为 Critical，另约 20 个可在无认证、无用户交互下远程利用（"可蠕虫化"）。最需优先处置的是两个已确认在野利用的本地提权零日：
- CVE-2026-85880：Windows ALPC 堆缓冲区溢出。低权限 AppContainer 内代码可利用其逃逸沙箱直达 SYSTEM，无需用户交互；为近四年来第二个 ALPC 零日（上一个为 2023 年初 CVE-2023-21674），由 Volexity/Proofpoint 上报。
- CVE-2026-81963：Windows Update Stack 链接解析不当 + 访问控制缺陷，低权限用户可提权至 SYSTEM；系该组件五年来修复的 7 个漏洞中首个被标记为零日者，由 MSTIC 发现。
两者 CVSS 均约 7.8（Important）但已被 CISA 确认在野利用并双双纳入 KEV（联邦机构处置截止 9/22），常被勒索/入侵链用作漏洞链"第二跳"。

同批其他高价值修复：Exchange Server RCE（CVE-2026-55007）、SharePoint Server RCE（CVE-2026-69465）、Remote Desktop Services RCE（CVE-2026-69525）、Microsoft Authenticator 提权（CVE-2026-80097）、SQL Server 提权（CVE-2026-65669）；总量含 Windows 723 个、Office 222 个。高校/科研机构普遍自托管 Exchange/SharePoint、成规模管理 Windows 终端与 SQL Server，建议按"已入 KEV 的两枚零日 → 面向公网的 Exchange/SharePoint/RDS → 其余 Critical"顺序排程，Windows 端点请尽快随本月更新通道统一推送。
