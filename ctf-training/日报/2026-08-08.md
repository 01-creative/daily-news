【高危·EDUSRC】CVE-2026-64638 — WordPress XSS2Shell：预认证 XSS 可串联至远程代码执行（CVSS 8.9）

WordPress 于 8 月 7 日公开 CVE-2026-64638（代号 XSS2Shell），影响 4.7 至 7.0.2 所有版本，全球约 43% 网站受影响。漏洞根因为 PHP `strip_tags()` 与 KSES 两套 HTML 解析器对 `< area>`（空格在 `<` 后）的判定差异：`strip_tags()` 不认为它是标签而放行，KSES 却将其解析为合法的 `<area>` 元素。攻击者在登录页输入特制用户名触发登录失败后，注入的 DOM 元素劫持 `ajaxurl` 变量，利用 WordPress 自带的 `user-profile.js` 自动向 REST API 发起 JSONP 请求，获得同源 JavaScript 执行——全程无需认证、无需用户交互。在满足管理员已登录等附加条件时，可进一步通过 OAuth Application Password 流程上传恶意插件实现 RCE。

WordPress 7.0.3 已修复，并向下回溯至 4.7 系列。GitHub 已出现多个公开 PoC，ProjectDiscovery 已发布 Nuclei 检测模板，大规模扫描预计即刻启动。高校门户、院系网站、学术博客大量基于 WordPress 构建，建议立即更新。

【中危·CNVD】CVE-2026-15816 — Red Hat dracut DHCP 命令注入漏洞（CVSS 7.5）

Red Hat 于 8 月 7 日公开 dracut（initramfs 生成工具）的命令注入漏洞：`die()` 错误处理函数在将 DHCP ROOT_PATH 数据写入 emergency hook 脚本时未做 shell 转义。若攻击者控制同一网段的 DHCP 服务器，可在 ROOT_PATH 中注入 `$(malicious_command)` 并在系统网络启动失败时以 root 权限执行。影响 RHEL 7–10 及 OpenShift Container Platform 4，但仅限使用网络/PXE 启动且依赖 DHCP ROOT_PATH 的场景，实际利用门槛较高。Red Hat 正开发补丁，建议网络启动环境部署 DHCP Snooping 并隔离 provisioning VLAN。
