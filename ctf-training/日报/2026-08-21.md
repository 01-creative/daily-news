【高危·EDUSRC】CVE-2026-73992 — WordPress Query Wrangler 插件代码注入 RCE（CVSS 9.9）

WordPress 查询构建插件 Query Wrangler（作者 Jonathan Daggerhart）≤ 1.5.57 存在代码注入（CWE-94）缺陷：攻击者仅需 Subscriber 级低权限账户、无需任何交互，即可在网络上远程注入并执行代码（AV:N/AC:L/PR:L/UI:N/S:C，机密性/完整性/可用性全高），可致整站沦陷、数据外泄甚至托管服务器失守。修复版本 1.5.58，建议立即升级，无法升级则临时停用插件。WordPress 是高校网站最普遍的建站平台，该类插件漏洞常被自动化批量扫描利用。

【高危·EDUSRC】CVE-2026-32475 — Elementor Pro 未经认证任意 PHP 文件上传致 RCE

Elementor Pro（< 4.2.2）文件上传模块存在逻辑缺陷：附件校验与保存由不同循环处理、对空文件名的响应不一致，攻击者可构造 multipart 请求绕过校验，将 PHP 后门写入 `wp-content/uploads/elementor/forms/`，直接访问该文件即以 Web 服务器权限执行任意代码、完全控制站点。前提是站点发布了带文件上传字段且启用多文件附件的表单（该选项默认关闭）。由 Patchstack 披露，8 月 20 日公开，暂无在野利用但技术细节已公开、预计很快武器化。注意：升级到 4.2.2 不会清除已植入的后门，升级后仍需审计上传目录中的 PHP 文件；免费版 Elementor（千万级安装）不受影响。

→ https://www.anti-malware.ru/news/2026-08-20-111332/51128

Catastrophic Learning: A New Attack Vector on Continual Learning Networks

提出针对持续学习（CL）模型"可塑性"的全新攻击面——"learning blockers"：攻击者操纵数据以削弱模型当前或未来训练轮次的学习能力，且因目标轮次数据尚未到达而难以察觉，与灾难性遗忘叠加形成"catastrophic learning"。论文给出威胁模型与 6 种攻击策略（Label/Tensor-Exchange、Attraction、Repulsion 等），在 MNIST 与 Split-CIFAR10 上对 DER、ER-ACE、iCaRL 三种策略进行 4480+ 次仿真验证。

📰 Rust 生态供应链攻击：arrayref 等三个热门 crate 被恶意重发布

Rust 安全响应团队 8 月 20 日确认一起供应链攻击：恶意 crate `proc-macro1` 的构建脚本会下载并执行恶意载荷，热门 crate `arrayref` 被重新发布并依赖该恶意 crate，作者名下的 `internment`、`append-only-vec` 同样被处理。恶意版本上线窗口：`arrayref@0.3.10`（86 分钟）、`internment@0.8.7`（90 分钟）、`append-only-vec@0.1.9`（107 分钟）；另删除 `proc-macro-en`、`aovine`、`arone`、`aronenao`、`tinymember` 等关联恶意 crate。作者账户已被锁定，官方判断系作者凭据/电脑被入侵而非本人作恶。建议开发者用官方提供的 `find` 命令排查 `~/.cargo/registry/cache` 中上述 crate 与版本，并核对 Cargo.lock。
