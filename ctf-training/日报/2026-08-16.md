【高危】CVE-2026-73678 — MindsDB Minds Platform 未认证远程代码执行（CVSS 10.0，公开 PoC，暂无正式补丁）

AI/机器学习数据库平台 MindsDB 曝出满分高危漏洞：其 FastAPI 后端暴露的 `POST /api/v1/responses/` 接口未做任何认证校验，攻击者可先经同样未认证的 `PUT /api/v1/settings/` 接口写入自己的 LLM API Key，再向内置 "Anton" 智能体提交恶意提示词，诱导其 scratchpad 工具经 `exec()` 无沙箱执行攻击者构造的 Python 代码，最终以服务进程权限执行任意系统命令。整条链无需认证、无需交互，叠加过于宽松的 CORS 配置（`allow_origins=["*"]` 且 `allow_credentials=True`）即可远程触发。影响 Minds Platform ≤ 26.1.0 全版本，公开 PoC（源自 GHSA-jcxw-h8ph-pxpv）已流出；截至披露时官方尚未发布正式修复版本，补丁仅存在于 main 分支。MindsDB 在高校 AI/ML 研究环境中逐步普及，建议立即将服务（默认端口 26866）收敛至可信网络、置于认证反代之后，并启用 `COWORK_REQUIRE_AUTH=true` 强制鉴权。

【高危】CVE-2026-58231 — SAP Commerce Cloud 满分 RCE 已遭在野利用（CVSS 10.0）

SAP 8 月 11 日补丁日（Security Note 3771065）修复的 SAP Commerce Cloud Data Hub Adapter 漏洞，因授权校验与输入验证不足，未经认证的攻击者可滥用默认认证客户端提交构造请求，实现任意代码执行并攻陷内部组件（CVSS 10.0）。威胁情报公司 Defused Cyber 于 8 月 15 日报告，其蜜罐在补丁发布仅三天后即捕获到利用尝试——在无公开 PoC 的情况下已进入实战阶段，攻击者身份尚不明；Shadowserver 统计互联网仍有 4,200+ 个暴露的 SAP Commerce Cloud 指纹（集中于欧美）。受影响分支为 COM_CLOUD 2211 / 2211-JDK21，修复版本 2211.55+ / 2211-jdk21.17+。该产品属企业级电商平台，高校典型场景极少部署，但使用 SAP 的校办企业应尽快升级，并可先用 IP Filter Set 临时限制 Data Hub Adapter 端点。

📰 韩国西江大学遭境外 IP 攻击，18 万条师生校友个人信息泄露，前总统朴槿惠亦在列

8 月 15 日，首尔西江大学（Sogang University）确认其统一登录（SAINT）账号系统遭境外 IP 攻击（韩媒多表述为暴力破解/随机尝试），约 18 万条在校生、研究生、教职工及校友个人信息泄露，含学号/工号、姓名、院系、邮箱、手机号及加密后的统一登录密码；校方称居民登记号、护照号等唯一标识未泄露。韩国媒体确认，1970 级电子工程系校友、前总统朴槿惠亦在受影响名单中。校方已封禁攻击 IP、实施网络隔离，并上报教育部与个人信息保护委员会，呼吁师生修改门户密码并警惕钓鱼电话/短信。这再次印证"统一身份认证 + 弱口令/暴力破解"是高校安全最薄弱的入口——建议国内高校同步核查 SSO 登录日志中的异常爆破行为并强制 MFA。
