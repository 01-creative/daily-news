【高危】CVE-2026-120338 — Prefab UI 生成式 UI 沙箱逃逸，可经 MCP 工具远程触发（CVSS 10.0）

11/1 公开（11/2 02:30 UTC+8）。prefab-ui 0.14.0–0.20.2 的 Generative UI 沙箱在 Deno 中以 `--allow-read/write/net` 无限制启动，Pyodide 的 `js` 模块可代理 Deno 全局，调用 `Deno.readTextFileSync` / `writeTextFileSync`，以服务进程用户读写文件，并可写入 `.pth` 持久化代码执行。常见入口是 FastMCP 的 `generate_prefab_ui` 工具：未开认证的 MCP 服务器，任何可达客户端都能调用；开了认证，任何有工具权限的客户端亦可。修复 **0.21.0**（加载后撤销 Deno 权限、`--no-prompt`、启动期仅允许 jsdelivr）。自建 MCP/生成式 UI 的 AI 实验室请升级，并给 MCP 工具加调用授权与出网白名单。
