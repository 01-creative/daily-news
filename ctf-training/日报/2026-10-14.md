【高危·EDUSRC】CVE-2026-104935 — Ivanti Connect Secure 未认证认证绕过→RCE 的 0day 链，已在野利用（CVSS 8.6）

**10/13** 三线同时引爆：Ivanti 公告、Volexity 披露、**CISA 当日列入 KEV**（联邦整改截止 10/16）。攻击者 **UTA0576**（新面孔，低置信度判为**犯罪**而非间谍动机）自 **10/3** 起打一台**已打全补丁**的 Connect Secure（22.8R2.4 Build 19097）。Volexity 还原出**三枚 0day 串链**：① **认证绕过**——请求 `/dana-na/auth/url_default/welcome.cgi` 时**URL 决定鉴权、`X-DSCGI-PATH` 头决定实际执行的脚本**，两者错位；② **文件写入竞态 RCE**——`wu.cgi` 把带 `.zip` 后缀的 Perl 脚本**先落盘**到 `/home/runtime/tmp/<MD5(filename)>`、**再**做 ZIP 校验，校验器随后删除，并行请求抢在窗口内执行；③ **提权**——篡改 `dsinvoked` root broker 信任的 DSCache 配置，把维护任务指向 Perl 解释器，看 `/etc/shadow` 确认 root 后再复原。①+② 合记 **CVE-2026-104935**（CWE-290，CVSS 3.0 **8.6**；③ 的独立提权补丁仍在排期）。**全程不落盘 web shell 或后门，命令与回显都藏在 exploit 用的 HTTPS 请求里**，并**选择性截断 `debuglog`/`audit.log`、自删载荷、把输出重定向到 `/dev/null`**——**Ivanti 的 Integrity Checker Tool 很可能查不出来**。后利用动作：域/LDAP 凭据抽取、AD 元数据转储、自研 Kerberoast 工具、专找 **LAPS 本地管理员口令与 BitLocker 恢复密钥**的 Python 检索、DNS/主机侦察、口令喷洒、经 `/data/.icscap/` 下改名的 tcpdump 抓包解析与**外带**。修复版 **25.1.1.2 / 25.1.3.0 / 25.1.3.1 / 22.8R2.5**（**22.7.x 及更早不受影响**）。

**高校要点**：Connect Secure（原 Pulse Secure）是**大量高校远程接入 VPN 的门面**——一条未认证链直通 root + AD，等于把统一身份、内网与证书一次性交出去。**立即升级到修复版**；无法即时的**断公网、只放必要来源**。更要紧的是：**"打上补丁"≠"没被入侵"**——该团伙痕迹在内存里，请按 Volexity 的 IoC（主机 `108.165.147[.]64`、`/data/.icscap/`、`X-DSCGI-PATH` 头、`/tmp/ml.py` 等）做**内存与网络取证**；疑似中招的按 Ivanti 流程**备份配置→恢复出厂→升级/重建→还原配置→轮换全部口令、证书、API Key 与授权服务器凭据**。

【高危】Nix / Lix 多漏洞可组合本地提权至 root（Nix 记 8.4/10）

**10/13** Nix 与 Lix 联合披露（**Guix 不受影响**，暂未分配 CVE，MITRE 工单在走）。核心三连：**无符号整数溢出**致堆越界写（任何对不可信表达式的求值）；**未授权 `repair`**——daemon 把上传的归档**先解包进最终 store 路径、事后才校验哈希**，校验失败恶意文件却已落盘，可**以 root 执行代码**（自 Nix 2.1 起，8.4/10）；**macOS Seatbelt 沙箱逃逸**（跨过内部尺寸阈值时可能发出无限定的 `(allow ...)`）。另 Nix 独有：脚本安装器遗留 **store 属主非 root**、macOS/FreeBSD 未沙箱时**未拒绝 build 用户连接**。修复版 **Nix 2.35.3 / 2.34.9 / 2.31.6 / 2.30.6 / 2.28.8**，**Lix 2.94.3 / 2.95.4**（Lix 请用 2.95.4 专用升级脚本，直接 `nix upgrade-nix` 会先卸掉 Lix）。**用 Nix 做构建/CI 与科研环境的实验室**请注意：**别把 daemon 当安全边界**（`allowed-users` 名单上的人在补丁前实际都能变 root），不可信表达式请丢到隔离机求值。

AI Models Can Provably Hide Arbitrary Capabilities（arXiv:2610.13928，已中 NeurIPS 2026；本窗口获媒体与社区广泛传播）

把"隐藏能力"从隐藏固定字符串推进到**隐藏任意可执行能力**：作者用 **digital locker** 把**加密后的神经网络**嵌进宿主模型权重，只有当**高熵密钥**触发时才解密并执行，在给定密码学假设下**即便完全掌握权重也"证明难被引出（unelicitability）"**。用**微调、权重加噪、梯度搜索触发词、潜在对抗训练**四种手段攻击一个化学反应用于预测（CBRN 代理任务）均被挡住，并开源了模型供防御研究。**要点**：这是对**"能力评估（elicitation）本身可作安全闸门"** 的**原理性反驳**——评测通过**不等于**没有危险能力，尤其当对手可主动埋后门时（论文亦坦言成本极高、仅证的是"该性质类"的困难性，不等于覆盖整个能力空间）。
