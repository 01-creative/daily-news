【中危·CNVD】CVE-2026-9317 — Nango 集成平台 runner tRPC 未认证 RCE（CVSS 4.0：9.2）

开源统一 API/集成平台 Nango（自托管 <0.71.6）的 runner 组件暴露 tRPC 服务处理任务（start/abort 等），但注册时未挂认证中间件、设计上的 RUNNER_SECRET_KEY 并未在该接口生效：能触达 runner 端口（默认 3005）的未认证攻击者可直接调用 start 在 runner 进程内执行任意 JavaScript，实现 RCE。9/4 NVD 公开，暂无在野利用、未入 KEV。修复版 0.71.6 引入 EdDSA JWT 内网认证，但新开关 NANGO_INTERNAL_AUTH_REQUIRED 默认关闭，仅升级仍"默认放行"，需显式开启。高校研发团队若自托管 Nango 做 AI 应用 OAuth/三方集成，请收敛 runner 网络暴露面并完整配置升级。

HookPry：操纵"生命周期钩子更新"即可接管 AI Agent 框架（arXiv:2609.03884，9/4 提交）

把 Agent 插件注册的"生命周期钩子"（会话启动、工具调用等事件绑定的 shell 命令）作为新攻击面：攻击者无需注入代码、仅篡改插件元数据更新即可静默替换为恶意命令，钩子以宿主权限在 LLM 完全不可见的时机执行。对 7 个主流 Agent harness 的 1000 次端到端攻击全部得手、单框架成功率最高 92.5%，Microsoft Defender 检出率 0%。提示 Agent 供应链风险已从模型权重延伸到"看似惰性"的钩子配置，钩子内容校验与最小权限执行应成为强制项。

→ https://arxiv.org/abs/2609.03884
