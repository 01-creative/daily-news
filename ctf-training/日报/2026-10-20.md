【高危·EDUSRC】CVE-2026-111057 — Mercury 未认证 `/api/terminals` 绕过，CVSS 10.0

10/19 公开。Mercury（mljar，3.0.0–<3.2.4）在 `block_handler.py` 的 `BLOCKED_PATTERNS` 中少写了一个逗号，`/lab` 与 `/api/terminals` 两条正则被 Python 拼成一条错误模式，导致终端 API 从未被拦截。默认无 token 部署下，匿名攻击者 `POST /api/terminals` 建终端、连 WebSocket，即可在服务进程权限下执行任意命令；公开 PoC 在默认 Docker 中直接拿到 **root shell**。修复 3.2.4，但**只补终端不够**：同一产品的 `/api/kernels` 仍可匿名建内核并提交 `execute_request`（CVE-2026-111058，9.8），3.2.6 才补。**请直接升到 3.2.6+（或最新），并设置 `MERCURY_TOKEN`**；只靠 blocklist 的部署等于没修。高校用它把 notebook 发布成教学/科研看板，常图省事关掉认证——请清点版本、把实例收到内网/SSO 后，已暴露的按“可能已失陷”排查进程、notebook 与凭据。
